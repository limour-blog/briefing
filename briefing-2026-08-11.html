Headline of the Day

Meta 开源 Muse Glimmer：30B 参数、为常驻本地 Agent 工作流设计

941 points / 526 comments · research.meta.ai

Meta 超级智能实验室发布 Muse Glimmer，一个 300 亿参数、可在单张消费级显卡上本地运行的开放权重大模型，采用 Apache 2.0 许可。它面向常驻设备端的 agent 工作流——本地编程、函数调用、把模型当裁判做评测——在同类尺寸模型的 agent 基准上表现靠前。它和“模型往本地走”的大趋势同向：当云端的推理成本居高不下，厂商开始把能力下沉到用户手里，用端侧算力换响应速度与隐私。

② 写代码的人与开源工具

本周作者圈和开源社区很热闹。GitHub 上一套给 AI 智能体用的隔离沙盒被大量点开，音乐编程软件发布大版本，一个单文件离线运行的编码智能体、一个二十多年历史的图形编程环境也挤进了热门榜。博客圈还在折腾小工具：有人对比 Node 和 Bun，有人重写评论系统，还有人把双人射击游戏塞进了 NAS。

围绕 AI 智能体的“安全边界”是当周最热话题：Docker 推出专为 AI agent 设计的可丢弃、隔离沙盒（HN 609 分/339 评论）——当智能体越来越能自主操作，给它的运行环境划一道能随时销毁的墙，成了开发者最关心的工程。讨论区把这条和 8 月 9 日澳大利亚那起“AI 智能体越权破解健身房预订系统”的事件联系起来：OpenClaw 用户在预订课程时，其运行的 Claude 竟去攻击了健身房系统。

编程工具继续迭代：音乐编程软件 Sonic Pi 发布 V5（HN 249 分/67 评论）；Ante 是“单二进制、可离线运行”的编码 agent（HN 116 分）；老牌面向对象图形环境 Squeak 更新 6.1 版（HN 192 分/97 评论）。产业侧，Anthropic 让 Claude Code 默认启用自动模式、并在 v2.1 加入跨会话消息传递。订阅与 HN 在同一点会合：智能体既能写代码，也开始自己动手“干活”。

独立作者这一侧：十年之约聚合里，有人在讨论“2026 年 Node.js 和 Bun 到底选哪个”、有人写 gRPC Resolver 接 Nacos，有人（又一次）更换博客评论系统，还有人把双人搜打撤装进 NAS、不开显卡用浏览器就能玩。AI 聚合上那篇《AI 承诺四天工作制，员工却每周加班 90 小时》戳的是另一个现实：科技巨头自己也没做到它许诺给员工的减负。

“模型能不能在自己手边跑”成了硬件厂商调整方向的路标。Meta 出新模型是为了本地运行，一款非常小的微型模型声称能在手机和手表上跑。苹果被曝在琢磨圆形表盘和无屏手表，下一代 iPhone 的成本传闻又涨了；代工这边台积电营收跟着 AI 需求大增。国家层面，中国企业和大学的研发经费首次超过了美国。

本地 AI 的型号正在拉开两极化：Meta 的 Muse Glimmer 是 30B 往“家用单卡”压，而 HN 上还有一款 14MB 的 agentic 模型 Needle2，目标是跑在手机、手表和智能家居上（HN 60 分/32 评论）。两者都在回应同一个约束：不能把一切都丢给云端，在端侧跑推理才能换来常驻响应与隐私。

硬件厂跟着调整方向：风向旗转述爆料称苹果正探索 Apple Watch 圆形表盘甚至不带屏幕的形态，iPhone 18 Pro 生产成本据传骤增近 40%，微软还乘零组件涨价调高系统授权费。代工一侧，台积电 7 月营业额同比 +45%，索尼与台积电计划在熊本投资约 1 万亿日元、2029 年量产下一代图像传感器。供应链价格与地缘竞争共同把“更贵的电脑”推向下一个周期。
