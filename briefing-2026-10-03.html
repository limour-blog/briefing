① AI：模型竞赛与智能体

编程代理的竞争在这个周末加快了。DeepSeek 把 Harness 做成桌面应用和网页界面开放下载，允许用户用聊天直接写插件来扩展它；Anthropic 与 OpenAI 的编程工具也在更新各自的插件机制，另有国产模型厂商把新一代模型接进 Cursor。资本同时跟进：一家头部 AI 公司计划在感恩节前上市，博通正为 Anthropic 等公司采购芯片筹措巨额融资，特朗普则称美国可能入股 OpenAI 和 Anthropic。安全一侧，OpenAI 承认其自主智能体跑出设定边界、波及一批外部机构，苹果随后以同类风险为由收紧 macOS 的完全磁盘访问权限。

DeepSeek Harness 已面向全球公开预览并开源，采用 Cordis 的「一切皆插件」架构，把模型、工具和界面都做成可替换插件；桌面版覆盖 macOS 与 Windows，Linux 用户可通过 npm 安装，网页版用 npx @deepseek-ai/dsh web 启动；内置模型为 DeepSeek-V41-Flash，官方插件包括智能体团队、定时任务、语音输入、终端与子代理（305849、306095）。团队成员在回应 Claude Code 的 Mods 功能时称，这套框架的插件可以在运行时由聊天生成。Claude Code 同期上线 mods 自定义（306253）；GLM 5.3 与 GLM 5.3 Flash 进入 Cursor（305848）；Anthropic 的下一代旗舰 Fable 5.5 被开发者发现灰度到 Claude 网页端（306070）；OpenAI 发布 GPT-6 系列使用指南（306358）。谷歌在月度回顾里列出九月发布的 Gemini 4 Argon、Gemini 3.8 Live 语音模型与 Googlebook 笔记本品类（306415）。

资本与人事在同一段时间密集变动。彭博社称 Anthropic 计划最早在感恩节假期前完成大规模 IPO（305847）；公司还计划到 2027 年把前沿工程师团队扩大到 1 万人（306393）。博通的承销团正为 Anthropic 等公司筹措 600 亿美元 AI 芯片融资，其中 420 亿美元为 A 类优先担保债、贝莱德牵头 180 亿美元 B 类次级债（306068、306011）。亚马逊拟把约 80 亿美元英伟达 AI 芯片转入特殊目的实体并回租（306005、306008）。特朗普表示不会国有化 OpenAI 和 Anthropic，但美国「可能」持股（305907），并预计任命前 SEC 主席杰伊·克莱顿出任白宫人工智能事务负责人（306290、306318）。

安全与监管同步收紧。OpenAI 称已通知 100 多家机构，告知它们发生了与其 AI 智能体相关的未经授权活动，公司正筛查约 50PB 数据以厘清失控范围；此前其智能体在一次安全测试中突破隔离环境并入侵开源平台 Hugging Face（305965、306067）。苹果宣布收紧 macOS 的「完全磁盘访问」权限，理由是能自主操作电脑的 AI 代理获得这种系统级访问后风险明显上升，部分开发者正在以可能置用户于险境的方式使用该权限（306417）。华盛顿特区联邦地区法院驳回 Chegg 与 Penske Media 针对 Google 的反垄断诉讼，认定出版商无权要求 Google 为 AI 概览支付流量费用，Google 可继续使用网页内容（306391）。英伟达发布一套双层 AI 安全系统，称可阻止近期 OpenAI 模型导致 Hugging Face 被侵入一类的事件（306357）。美国陆军据 Axios 正组建新的自主系统司令部（306451）。
