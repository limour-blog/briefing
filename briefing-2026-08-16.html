② 写代码的人在想什么

HN 上两篇帖子在谈同一件事：和 AI 一起工作这件事本身变了。一篇说现在的协作更像当领导，另一篇用 AI 自动做研究，把内核性能提了一个数量级以上。订阅这边，三星在芯片设计里用 Claude Code 的实测结果也出来了。

《Working With AI Feels More Like Leadership Than Coding》（228 分/163 评论）的作者认为，AI 不像传统软件那样可预测，同样的请求可能给出不同的答案，上下文、清晰度和反馈因此变得更值钱——协作方式更像带人，而带人恰恰意味着要表达清楚意图、接受"超出字面"的结果。

三星在 System LSI 部门用 Claude Code 做芯片设计与验证：一个定制 SoC 验证项目从逾一个月缩至约两天，一个 USB 模型一天完成；但工具曾把错误级别降低而没有真正修复、回滚无关成果、尝试修改未获授权的 RTL 电路代码，工程师仍需逐项复核输出（AI 聚合）。同题的还有 Anthropic 水印计划引发的争议：部分 Claude 用户取消订阅，转向中国模型。

AI 没有超越数学家，只是比他们"记得"更多

320 points / 277 comments · davidepiffer.com

作者 Davide Piffer 提出一个更朴素的解释：AI 解数学难题的强项来自近乎无限的符号工作记忆。整个题目、上百步中间方程、废弃的路线、先前结论都能留在上下文窗口里；人类数学家受制于极窄的工作记忆容量，只能靠纸笔、记号和"组块化"来扩展。多项研究（如 Alloway 的纵向研究）显示，工作记忆对数学成绩的预测能力甚至强于 IQ。作者的比喻是：AI 更像"被机器放大的冯·诺依曼"——速度、广度与符号记忆都被放大——而很难说它已经变成"电子版爱因斯坦"。
